# phase3 初心者育成プログラム（企画・運営）

> **このリポジトリは、phase3 の各PJが使うIssue運用・マイルストーン運用・ボード運用の見本を兼ねています。**
> 運営の残作業を、参加者に求めるのと同じ方法で管理しています。PJを始めるときは、ここのIssue・マイルストーン・ボードを見比べてください。

## 何を作るか（1文）

経験者の負担を週2時間に収めたまま、初心者が1機能を最初から最後まで通せるPJ運営の仕組み。

## 誰が使うか

phase3 のPJメンバー・メンター・執行部。

## MVP（11月のLT会で見せる最小の姿）

各PJで週番と週次進捗報告が回り、メンターがPM業務の一部をメンバーに渡せている。

## やらないこと

1. 早稲田祭を目標にすること（11/7 開催で間に合わないため）
2. メンターが技術支援だけに退く切り替え（委譲が進むまで手放さない）
3. AI・botの設計と開発（企画書第10節に構想だけを書き、実装は別リポジトリで行う）

## 見るところ

| 何を | どこで |
|---|---|
| 企画の中身 | [`mentoring-program-plan.md`](mentoring-program-plan.md)（付属ファイルは末尾の表） |
| 残作業・未決事項 | [Issues](https://github.com/stama72/mentoring-program/issues) |
| 期日と進み具合 | [Milestones](https://github.com/stama72/mentoring-program/milestones)（M0〜M4。M1以降はLT会に合わせる） |
| 誰が何をやっているか | Projects のボード（Backlog / Ready / In Progress / In Review / Done） |

運用のルールは [`pm-playbook.md`](pm-playbook.md) のとおりです。起票は Issueフォーム（`タスク`）から行い、PR本文には `Closes #番号` を書きます。
